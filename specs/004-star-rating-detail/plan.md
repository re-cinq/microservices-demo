# Implementation Plan: Star Rating on Product Detail Page

**Branch**: `004-star-rating-detail` | **Date**: 2026-05-20 | **Spec**: [spec.md](spec.md)

**Source**: Jira AIP-153 (parent epic AIP-95)

---

## Summary

Add a static star rating to the product detail page. Rating values (0.0–5.0 float) are seeded in `productcatalogservice/products.json`, surfaced through the existing `Product` protobuf message (new field 7), and rendered in the `product.html` template alongside the product name. No new services, datastores, or infrastructure are introduced.

---

## Technical Context

**Language/Version**: Go 1.21 (frontend), Go 1.21 (productcatalogservice)

**Primary Dependencies**: gRPC / protobuf (existing); Go `html/template` (existing)

**Storage**: In-memory catalogue loaded from `products.json` at startup — no new datastore

**Testing**: `go test ./...` in each service directory

**Target Platform**: Linux container (existing Skaffold/Kubernetes pipeline — unchanged)

**Project Type**: Microservices web application

**Performance Goals**: No new network calls; rating is carried in the existing `GetProduct` gRPC response — zero latency overhead

**Constraints**:
- No new services, datastores, or infrastructure
- No CI or deployment manifest changes
- All changes must match existing Go language and patterns
- Existing pipeline must ship the feature unmodified

**Scale/Scope**: One new proto field; two file edits (proto + JSON); one template edit
