# Implementation Plan: Category Jump Links

**Branch**: `attendee/pontus-vepsalainen` | **Date**: 2026-06-16 | **Spec**: [spec.md](spec.md)

**Input**: [specs/001-category-jump-links/spec.md](spec.md)

## Summary

Add category jump links to the product list page so shoppers can jump to a category section in one click instead of scrolling. Products are grouped under category headings derived in-memory from the existing product catalogue. No backend, datastore, or infrastructure changes — two files change: `src/frontend/handlers.go` (grouping logic) and `src/frontend/templates/home.html` (updated layout).

## Technical Context

**Language/Version**: Go 1.21 (matches existing frontend service)

**Primary Dependencies**: `html/template` (stdlib), Gorilla Mux (existing), gRPC proto types (existing `pb.Product`)

**Storage**: N/A — no persistence; grouping is in-memory per request

**Testing**: Go stdlib `testing` package (`go test ./...`)

**Target Platform**: Linux server (existing deployment, unchanged)

**Project Type**: Web service (server-side rendered frontend)

**Performance Goals**: No additional latency beyond an in-memory slice sort; existing `ListProducts` gRPC call is unchanged

**Constraints**:
- Only existing services — no new services
- No new datastore — category data from `productcatalogservice/products.json` via existing gRPC call
- Language and patterns must match Go frontend conventions
- No infrastructure / CI / deployment manifest changes

**Scale/Scope**: ~10 products, ~6 categories in current `products.json`; grouping is O(n) in product count
