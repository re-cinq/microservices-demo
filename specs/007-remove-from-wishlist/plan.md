# Implementation Plan: Remove a product from the wishlist

**Branch**: `007-remove-from-wishlist` | **Date**: 2026-05-20 | **Spec**: [spec.md](spec.md)

## Summary

Add a "Remove" action to the wishlist so shoppers can delete individual items. The change is minimal: a new `POST /wishlist/remove` route, a handler that filters the product ID out of the session's `wishlists sync.Map` slice, and a "Remove" button form added to each product card in `wishlist.html`. No new files beyond the handler addition; no structural changes to existing types or state.
