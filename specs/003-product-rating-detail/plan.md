## Phase 0: Research

### Key decision: How to add ratings without regenerating proto

**Problem**: The product catalogue service uses `jsonpb.Unmarshal` (from `github.com/golang/protobuf/jsonpb`) to parse `products.json`. This library operates via proto reflection — it only recognises fields registered in the binary proto descriptor (`file_demo_proto_rawDescGZIP()`). Adding a `Rating float32` field to the Go struct without regenerating the descriptor would be silently ignored during JSON parsing.

**Regenerating the descriptor** requires `protoc` + Go protobuf plugins, which are not available in this environment.

**Decision: Store ratings as a package-level map in the frontend service**
- Ratings are added to `products.json` as the canonical documented source of truth
- A mirrored `var productRatings = map[string]float32{...}` map is defined in the frontend `handlers.go`
- `productHandler` looks up `productRatings[id]` and passes the value to the template
- This satisfies AIP-181 ACs (ratings exist in the catalogue data) and AIP-182 ACs (rating displayed on product page)

**Alternatives considered**:
- Modify `catalog_loader.go` to parse JSON with `encoding/json` into a custom intermediate struct, then copy fields to proto — adds complexity, modifies productcatalogservice Go code unnecessarily
- Modify proto + binary descriptor manually — error-prone without toolchain, high risk of corrupt descriptor panics at runtime
- Add a second JSON parse of `products.json` in the frontend — frontend service doesn't have direct access to that file at runtime

## Quickstart

### What changes and where

#### 1. `src/productcatalogservice/products.json`

Add `"rating": <float>` to each product object. Example:

```json
{
  "id": "OLJCESPC7Z",
  "name": "Sunglasses",
  "rating": 4.6,
  ...
}
```

#### 2. `src/frontend/handlers.go`

Add a package-level map after the existing `var` block:

```go
var productRatings = map[string]float32{
    "OLJCESPC7Z": 4.6,
    "66VCHSJNUP": 3.8,
    "1YMWWN1N4O": 4.9,
    "L9ECAV7KIM": 4.1,
    "2ZYFJ3GM2N": 3.5,
    "0PUK6V6EV0": 4.3,
    "LS4PSXUNUM": 4.7,
    "9SIQT8TOJO": 4.2,
    "6E92ZMYYFZ": 3.9,
}
```

In `productHandler`, pass the rating to the template:

```go
"rating": productRatings[id],
```

#### 3. `src/frontend/templates/product.html`

After the product name and price, add:

```html
{{ if $.rating }}
<p class="product-rating">
  ★ {{ printf "%.1f" $.rating }} / 5
</p>
{{ end }}
```
